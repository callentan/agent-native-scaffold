# Agent 接入与验证记录

**GitHub Copilot App 是首测目标，目前未测试。** 客户端名称的选择不是兼容性结论，也不能从其他界面或版本的行为推断 App 已支持某项入口。

<a id="reading"></a>
## 通用文件读取路径

人可从 [README 的活动导航](../README.md#activities)开始；能读取仓库文件的 Agent 可先显式读取根目录 [AGENTS.md](../AGENTS.md)，再沿链接读取任务所需的事实、开发说明、验证与日志。不要求个人或全局 skill、参考仓库权限或隐藏聊天记录。

可以用自然语言发起，实际任务输入由用户填写：

```text
请先读取仓库根目录 AGENTS.md，再读取与本次任务有关的资料。
本次目标、范围、依据与完成条件：【待填写】。
先核对 Git 状态和未决项；缺少行为事实、开发输入或授权时说明缺项，
不要补造需求、选择技术栈或把未执行的检查写成通过。
```

这只是显式读取的使用方式，不证明客户端会自动加载文件。P2 专用 instructions、agents、skills 和 prompt files 尚未提供；以后即使提供 prompt 快捷入口，也只是可选便利，不是完成任务的必要条件。

<a id="evidence-types"></a>
## 分别记录四类依据

| 类别 | 可以说明什么 | 不能据此说明什么 |
|---|---|---|
| 原生发现 | 在指定客户端、版本和环境中，未显式要求读文件时，实际观察到入口被发现和使用 | 不能仅凭文件存在或手动读取断言原生发现 |
| 显式文件读取 | 明确要求读取后，实际观察到文件被读取并用于当前任务 | 不能推出自动发现、其他入口或其他客户端也可用 |
| 仅官方文档依据 | 有对应客户端/功能的官方资料，记录链接、查阅日期及适用版本 | 不能替代本项目中的实际验证 |
| 未验证 | 尚无足够观察；缺版本、缺环境或未执行都要说明 | 不能写成支持，也不能未经测试写成不支持 |

<a id="boundaries"></a>
## 权限与运行边界

复制 Markdown 或显式读取 AGENTS 不会启用 sandbox、审批、CI、分支保护或工具限制。这些能力必须由客户端、操作系统和托管平台实际配置并核验。文件中的规则不是强制安全机制，角色名称、自审结论也不能代替授权人的决定。
