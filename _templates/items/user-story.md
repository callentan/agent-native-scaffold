<a id="checklist"></a>
## 实施清单

- [ ] 待填写：一个具体工作项及其输入。
- [ ] 待填写：相关验证与记录工作。

清单只跟踪工作，不新增一套业务/软件验收。按需拆分步骤；状态可改为 `in-progress`、`blocked`、`review-ready` 或 `done`，变更时留下实际依据。

<a id="records"></a>
## 记录入口

| 内容 | 实际链接或缺项 |
|---|---|
| 修改的工件、实现或审阅记录 | 待填写 |
| VT、独立维护检查及原始结果 | 待填写，尚无执行记录 |
| 开发日志与交接 | 待填写 |
| 缺口、待复核及未执行项 | 待填写 |
| 阻塞、范围变化依据与下一步 | 待填写 |

VT 直接回到 REQ/SR、必要设计或独立维护完成条件，US 不是必经层级。`done` 不自动表示需求已通过验收、合并或上线。
