## 本次变化

- P1 建立资料入口、七类表单、开发与接入说明、空 `src` 指引、通用入口及 PR 表单。P2 新增六个共享方法、三个工作模式、五个可选 prompts 和三份 instructions，README 与 AGENTS 指向同一套方法。

<a id="handoff"></a>
## 阻塞与下一步

下一步是完成上述 P3 人与客户端操作，不是再次制作 P1/P2，也不是选择业务技术栈。使用干净副本与计划的同一组输入，分别记录原生发现、显式读取和人工路径；修订后重新检查实际受影响项。

接手先核对分支、P1/P2 commit、本记录之后的提交和 README 未提交排版；检查原始 artifacts 是否仍可访问。旧候选与最终候选保留各自 receipt，不混用基线。演练助手不是模板工具，旧 B1 助手可能重写快照，不能直接对已变更的副本复跑它并复用旧结果。

没有推送、PR、发布或远端权限操作待重放；任何后续外部操作仍需相应授权。
